# Akshay Kumar Boddu — Portfolio

React 18 + TypeScript + Vite + Tailwind CSS 3 + Framer Motion.

## Run

Requires Node.js 18+ (https://nodejs.org).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Edit content

Everything (text, skills, projects, experience, links) is in `src/content.ts`.
Images live in `public/photos/`; the résumé is `public/resume.pdf`.

## Deploy

Push to GitHub and import the repo in Vercel or Netlify (build command `npm run build`, output directory `dist`).
Before sharing, set `og:image` in `index.html` to the full deployed URL so link previews work.
